# SleepWell — 소빈 작업 저장소

학술제 「물리기반 잔차학습을 통한 생체리듬 복원 및 개인 맞춤형 컨디션 관리 시스템 개발」 팀 SleepWell의 **안드로이드 앱(프론트엔드) 작업물**을 보관하는 저장소입니다.

* 백엔드(채윤) 저장소: [https://github.com/iuniion3287-web/SleepWell](https://github.com/iuniion3287-web/SleepWell)

## 최신 버전: `통합 v3/` (2026-10-02)

채윤 백엔드(1분 버전)와 소빈 화면을 합친 Android Studio 프로젝트입니다.

|기능|내용|
|-|-|
|1분 epoch|팀 공통 기준(9/26 회의)에 맞춰 30초 → 1분으로 변경|
|시간대|Samsung Health 원본 시각을 UTC로 읽고, 화면에서 한국 시간(KST)·UTC 중 선택해 표시. 계산·내보내기는 KST 기준|
|날짜별 조회|"밤"(정오\~다음 날 정오) 단위로 지난 날짜를 골라 그 시점 기준으로 다시 계산|
|분석|삼성 CSV 업로드 → 1분 타임라인 → Two-Process 모델(S, C, 수면 성향) → 결과 화면·그래프|
|직접 입력|최근 취침·기상 시각을 입력하면 수면으로 반영해 재계산|
|연구자 화면|1분 epoch 표, CSV·JSON 내보내기|

변경 내역과 근거는 `통합 v3/CHANGES\_소빈\_통합.md`에 있습니다.

### 실행 방법

1. Android Studio → **Open** → `통합 v3` 폴더 선택 (New Project 아님)
2. 첫 Gradle Sync가 끝나면 에뮬레이터에서 실행
3. `local.properties`는 PC마다 경로가 달라서 넣지 않았습니다. Android Studio가 자동으로 만듭니다.

### 주의

* **개인 데이터는 포함하지 않았습니다.** 앱의 "샘플" 버튼이 쓰던 실제 수면 기록 CSV(`app/src/main/assets/`)는 업로드에서 뺐기 때문에, 샘플 버튼은 파일 없음 오류를 표시합니다. 분석하려면 직접 CSV를 업로드하세요. (합성 데모 데이터로 교체 예정)
* 빌드 결과물(`build/`, `.gradle/`, `.idea/`)은 포함하지 않았습니다.
